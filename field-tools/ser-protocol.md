# S-E-R Protocol

## STOP
Interrupt the sequence when something is unclear, contradictory, unsafe, or inconsistent with observed reality.

## ESTABLISH
State the discrepancy in concrete terms. Separate observation from interpretation.

## RESOLVE
Clarify the required state, authority, or action before continuing.

```
STOP → ESTABLISH → RESOLVE
```

The protocol is designed to convert a soft concern into an operational interruption.

Use authoritative domain procedures where they prescribe different or additional language.
