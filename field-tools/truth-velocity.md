# Truth Velocity Check

**Truth Velocity** asks how quickly consequential bad news reaches someone able and authorized to act.

For a selected failure mode, capture:

- time the signal first became observable
- time someone recognized it
- time it was communicated
- time the accountable decision-maker received it
- time required action began
- blockers, handoffs, hierarchy, or ambiguity that added delay

The objective is not faster messaging at all costs. It is reducing avoidable latency between reality changing and the operating system responding.
