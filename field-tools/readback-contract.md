# Readback Contract

Critical communication should close the loop.

```
STATE → CONFIRM → EXECUTE → VERIFY
```

## State
Transmit one specific action or condition.

## Confirm
Receiver reads back the meaningful value, action, or constraint.

## Execute
The action occurs.

## Verify
Confirm the resulting state.

A generic acknowledgment such as “okay” is not proof of shared understanding.

Domain-specific regulated phraseology and procedures take precedence over this general tool.
