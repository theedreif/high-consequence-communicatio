# Gap Check

Use before or during a consequential handoff.

- **SAID** — Was the instruction specific?
- **HEARD** — Was receipt acknowledged?
- **UNDERSTOOD** — Was meaning read back rather than merely agreed to?
- **ACTED** — Did the intended action occur?
- **VERIFIED** — Was the result confirmed?

If any link is unknown, the communication loop is open.

**Do not confuse acknowledgment with understanding.**
